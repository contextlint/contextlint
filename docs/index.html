Why most of these tools lie to you

Every "prompt optimizer" adds its findings together and reports the total. That number is wrong, because the findings overlap. JSON indentation is also whitespace. A duplicated block also contains duplicated sentences. Summing them inflates the headline — sometimes by two times.

contextlint doesn't sum. It applies every provably-safe transformation to your actual text, re-counts the tokens, and reports the measured difference. Then it hands you the rewrites so you can check its work:

$ contextlint prompts/ --fix ./rewritten   # originals untouched
$ diff -u prompts/agent.md rewritten/agent.md

The same honesty rule applies to money. Without --price-in, contextlint uses a placeholder rate and says so in capital letters every single time. It will not quietly invent a price for your model and then quote you savings based on it.

Three confidence classes, and they mean something

ClassWhat it means
MEASUREDTokens removed and re-counted. Cannot change model behaviour — trailing whitespace, blank-line runs, minifiable JSON, verbatim duplicate sentences.
HIGHA provider feature recovers it, chiefly prompt caching of a stable prefix. No content change required.
JUDGEMENTThe prize is quantified but not claimed. Few-shot trimming, filler removal, over-retrieval. Run your evals.

Stripping trailing spaces and deleting half your few-shot examples are not the same kind of act. A tool that reports them as one number is not helping you.

What it finds

CheckFinds
repeated-system-promptA fixed system prompt billed on every single call. Usually the largest line on the bill and the least noticed, because per-call it looks small.
cacheable-prefixA stable leading block over the ~1024-token caching floor that you're paying full price for every time.
pretty-printed-jsonindent=2 retrieval payloads. Found by balanced-brace scanning, so nested objects can't hide from it.
duplicate-blocksParagraphs repeated verbatim across calls, outside the cacheable prefix.
restated-instructionsThe same sentence twice in one prompt — what happens when three people edit a prompt over a year.
whitespace-bloatTrailing spaces, blank-line runs, alignment padding. Never touches fenced code blocks.
filler-phrases"You are a helpful assistant", "take a deep breath", "I will tip you $200", and other folklore.
tool-schema-costTool schemas re-sent on every call. In an agentic loop this multiplies by steps per task — a 6-step task pays for the whole toolbox six times. Almost nobody measures it, because it lives in code not in the prompt.
unused-tool-schemasTools you declare on every call that the model never actually invokes.
unbounded-historyFull conversation history re-sent each turn, so cost grows with the square of the conversation length.
io-imbalanceHuge inputs producing tiny outputs — the signature of over-retrieval, and often the biggest line on a RAG bill.

Limitations, stated plainly

The default counter is an approximation — it mimics the cl100k pre-tokenizer and models sub-token splits including identifier boundaries, typically landing within about 10%. Every report says which backend produced its numbers. pip install tiktoken alongside it and exact counts are picked up automatically.

The caching figure assumes a conservative 50% discount on cached reads; most providers do better. Image and audio tokens aren't counted, only text. And JUDGEMENT findings are prizes, not promises — contextlint cannot run your evals for you.

No telemetry, no phone-home, no API key, no upload step. There is no HTTP client anywhere in the codebase and you can verify that in about a minute.
